# Governed search bearer capability

Use a fresh internal workload capability for each attempt, including retries. It is not an OpenClast session token or a desktop credential. An operator can temporarily accept the legacy actor-bearing shape described below; `multi_room=closed` applies to both shapes. Send the JWS in `Authorization: Bearer <token>` (the prefix is case-sensitive; [auth.rs:51–70](../../../daemon/crates/kwiry/src/auth.rs#L51-L70)).

## Compact JWS header

The token is a compact signed JWS. The header and payload use unpadded base64url. Duplicate member names at any nesting level and JSON containers nested to depth 128 or more are rejected before accepting the signed document ([capability.rs:260–318](../../../daemon/crates/kwiry/src/capability.rs#L260-L318), [capability.rs:435–483](../../../daemon/crates/kwiry/src/capability.rs#L435-L483)).

| Member | Required/type | Check |
|---|---|---|
| `alg` | Required string | Exactly the algorithm configured for `kid`; supported pairs are `EdDSA`/Ed25519, `ES256`/P-256 and `RS256`/RSA. Signature verification uses that public key; symmetric keys are prohibited. [capability.rs:288–318](../../../daemon/crates/kwiry/src/capability.rs#L288-L318), [capability.rs:485–507](../../../daemon/crates/kwiry/src/capability.rs#L485-L507) |
| `kid` | Required nonblank string | Exact lookup in the configured JWKS; no trimming for lookup. JWKS must have at least one key, nonblank distinct `kid`s, matching `alg`, `use: "sig"` and exactly `key_ops: ["verify"]` per key. [capability.rs:180–215](../../../daemon/crates/kwiry/src/capability.rs#L180-L215), [capability.rs:288–296](../../../daemon/crates/kwiry/src/capability.rs#L288-L296) |
| `typ` | Required string for workload; optional for legacy | If present, exactly `kwiry-cap+jwt`; `null` is not omission. Omission is only accepted for actor-bearing legacy claims. [capability.rs:55–64](../../../daemon/crates/kwiry/src/capability.rs#L55-L64), [capability.rs:101–113](../../../daemon/crates/kwiry/src/capability.rs#L101-L113), [capability.rs:277–287](../../../daemon/crates/kwiry/src/capability.rs#L277-L287) |
| `crit` | Must be absent | Any presence, even `null` or `[]`, is rejected. [capability.rs:55–64](../../../daemon/crates/kwiry/src/capability.rs#L55-L64), [capability.rs:149–153](../../../daemon/crates/kwiry/src/capability.rs#L149-L153), [capability.rs:274–281](../../../daemon/crates/kwiry/src/capability.rs#L274-L281) |

Other noncritical header members are not used by Kwiry to select keys or authorize search; they are not rejected as unknown ([capability.rs:55–64](../../../daemon/crates/kwiry/src/capability.rs#L55-L64), [capability.rs:288–318](../../../daemon/crates/kwiry/src/capability.rs#L288-L318)).

## Claims

Members are required unless marked otherwise. `iss`, `aud`, `sub`, `actor` and `jti` are not normalized. No additional application-specific string length limit is imposed on those members. Workload claims are closed at the top level, within each resource and within `constraints`; legacy claims ignore unrecognized members at those levels (but still reject duplicates). [capability.rs:66–99](../../../daemon/crates/kwiry/src/capability.rs#L66-L99), [capability.rs:115–141](../../../daemon/crates/kwiry/src/capability.rs#L115-L141), [capability.rs:321–354](../../../daemon/crates/kwiry/src/capability.rs#L321-L354)

| Member | Type | Check |
|---|---|---|
| `iss` | String | Exact configured issuer. [capability.rs:298–303](../../../daemon/crates/kwiry/src/capability.rs#L298-L303), [capability.rs:326–332](../../../daemon/crates/kwiry/src/capability.rs#L326-L332) |
| `aud` | String, not an array | Exact configured audience. [capability.rs:67–70](../../../daemon/crates/kwiry/src/capability.rs#L67-L70), [capability.rs:298–303](../../../daemon/crates/kwiry/src/capability.rs#L298-L303), [capability.rs:326–332](../../../daemon/crates/kwiry/src/capability.rs#L326-L332) |
| `sub` | Nonblank string | For workload, exact bytewise membership in `auth.openclast.workload_subject_allowlist`; an empty list admits no workload subjects. For legacy, nonblank represented subject distinct from `actor`; the workload allow-list is not applied to legacy. [capability.rs:326–354](../../../daemon/crates/kwiry/src/capability.rs#L326-L354) |

| `jti` | Nonblank string | Required for both shapes. Only workload tokens are subject to one-use replay enforcement, described below. [capability.rs:231–251](../../../daemon/crates/kwiry/src/capability.rs#L231-L251), [capability.rs:326–332](../../../daemon/crates/kwiry/src/capability.rs#L326-L332), [capability.rs:419–431](../../../daemon/crates/kwiry/src/capability.rs#L419-L431) |

## Replay and narrowing

- At startup the **replay epoch** is the maximum of the daemon's startup Unix second, the persisted prior epoch and the persisted issued-at watermark. A workload token must have `iat > epoch`; minting in the daemon's startup second is too early. The clock high-water mark also prevents a time rollback from making an expired token live again. [capability.rs:163–175](../../../daemon/crates/kwiry/src/capability.rs#L163-L175), [replay.rs:25–47](../../../daemon/crates/kwiry/src/replay.rs#L25-L47), [replay.rs:56–88](../../../daemon/crates/kwiry/src/replay.rs#L56-L88)
- Each accepted workload `jti` is reserved across workload subjects in this daemon until expiration; reuse produces `401 unauthorized`. The reservation happens during authentication, so a later rejection by request parsing or retrieval still consumes the token. An unavailable replay store/verifier produces `503 replay_state_unavailable`. [replay.rs:56–89](../../../daemon/crates/kwiry/src/replay.rs#L56-L89), [capability.rs:231–251](../../../daemon/crates/kwiry/src/capability.rs#L231-L251), [auth.rs:75–96](../../../daemon/crates/kwiry/src/auth.rs#L75-L96)
- Request filters intersect the signed resources by exact `vault_id`/`room` equality; they never add authority. An empty intersection succeeds with no hits. A signed resource outside that intersection does not produce an availability error; if any resource *inside* it is unavailable, no partial hits are returned and its position in the signed array is reported. [runtime.rs:636–660](../../../daemon/crates/kwiry-core/src/runtime.rs#L636-L660), [runtime.rs:793–825](../../../daemon/crates/kwiry-core/src/runtime.rs#L793-L825), [server.rs:791–800](../../../daemon/crates/kwiry/src/server.rs#L791-L800)
