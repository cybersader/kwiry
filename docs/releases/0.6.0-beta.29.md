# kwiry-search 0.6.0-beta.29

This release restores complete sanitized diagnostics export when the active vault adapter cannot provide a local desktop filesystem root.

## Full-report clipboard fallback

The existing hardened desktop file exporter remains the preferred path for ordinary local vaults. It still requires an absolute canonical vault root, refuses destinations inside the active vault, rejects unsafe existing targets, writes through an owner-only temporary file, enforces the 16 MiB ceiling, and publishes atomically.

When that desktop path cannot be composed, selecting **Export full report…** now copies the complete sanitized report to the clipboard. The success notice instructs the user to paste it into a text file outside the active vault and clear the clipboard afterward.

This fallback is distinct from **Copy summary**:

- **Copy summary** remains capped at 64 KiB and may omit retained events.
- **Export full report…** includes the complete human-readable report and structured records up to the existing 16 MiB full-export ceiling.

The clipboard operation is invoked directly from the settings-button action so browser permission remains available. Cancellation and clipboard permission failures remain fixed categorical outcomes, and a selected desktop export attempt is never bypassed after cancellation, destination refusal, or write failure.

## Privacy and isolation

The diagnostics privacy boundary is unchanged. Neither export path includes raw queries, source identities, paths, excerpts, content, SQL, raw execution plans, arbitrary backend messages, stacks, credentials, or tokens.

The clipboard host receives only validated serialized byte chunks. It has no vault, filesystem, Electron, Worker, network, or object-URL authority. Production build checks require both export transports in the main bundle and exclude them from the Worker bundle.

## Compatibility

This release does not change search behavior, diagnostics schema, Worker protocol, cache schema, source identity, chunk identity, extraction behavior, or persisted index storage. No reindex is required.

## Verification

Automated coverage includes desktop capability selection, missing and invalid adapter paths, unavailable Electron authority, synchronous clipboard invocation, split UTF-8 reconstruction, exact full-report size bounds, fixed failure outcomes, unchanged summary limits, desktop containment enforcement, privacy validation, and Node 22/24 Gate 5 lifecycle checks.
