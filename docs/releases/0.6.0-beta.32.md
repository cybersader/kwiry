# kwiry-search 0.6.0-beta.32

This release prevents completed lexical searches from being discarded during diagnostic trace finalization and stops the Obsidian status bar from shifting when the in-flight count changes between one and two digits.

## Search reliability

In-plugin lexical searches can inspect observations across many bounded lanes while retaining at most 512 unique candidates. Trace validation now distinguishes that larger bounded observation total from the retained-candidate ceiling. If optional per-stage trace detail cannot be represented safely, Kwiry stores a bounded execution summary instead of failing a search whose ranked results are already valid.

Candidate collection, ranking, result limits, lexical-v1 compatibility, and the shared Rust query plan remain unchanged. The repair affects post-search observability only; it does not widen retrieval or silently retry with another mode.

## Status bar stability

The Obsidian status-bar in-flight count now renders in a dedicated two-digit, tabular-width span. Single-digit values are zero-padded (`04`, `09`) while double-digit values remain unchanged, preventing neighboring status items from shifting as work completes.

The search modal's progress wording and indexing behavior are unchanged.

## Compatibility and migration

Worker protocol 15, cache schema 12, diagnostics schema, persisted index layout, source preparation, format identity, and public search response bounds are unchanged. No migration is required; existing disposable cache data remains compatible.

## Privacy

The diagnostics and search-response privacy boundaries are unchanged. No query text, source identity, path, excerpt, SQL, execution plan, arbitrary backend message, stack, credential, or token is added to diagnostics.

## Verification

Automated coverage exercises high-observation multi-lane trace finalization, production Worker search completion, protocol bounds, one- and two-digit status rendering, fixed-width CSS, and ordinary status text. Existing Node 22/24, package privacy, deterministic evidence, license and notice, real-host WebDriver, immutable candidate, and protected publishing gates remain in force.
