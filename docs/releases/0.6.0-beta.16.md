# kwiry-search 0.6.0-beta.16

This release publishes the beta.15 plugin behavior through the new immutable tested-byte release lane. The prepared production package is exercised in a pinned real Obsidian runtime through Selenium WebDriver before publication, then the exact tested bytes are handed to a data-only publisher that does not rebuild or execute candidate code.

## No index rebuild

Beta.16 does not change the plugin cache schema, Worker protocol, source-preparation schema, ranking contract, or Rust extractor identity. Users updating from beta.15 keep their existing disposable index and do not pay another rebuild solely because of this release.

## Tested-byte publication

The release candidate is bound to:

- the exact beta.16 tag commit;
- one explicitly selected successful full CI run;
- the exact production package file set and candidate-set hash;
- a pinned Obsidian 1.13.7 application on the 1.13.4 installer runtime;
- Electron 43.1.1 and matching Chromium/ChromeDriver 150.0.7871.114;
- Selenium WebDriver 4.39.0;
- closed aggregate-only WebDriver evidence and complete cleanup assertions.

The real-host scenario enables Excel in a disposable vault, selects the generated `.xlsm` result with a native WebDriver click, requires one resolved real `openFile` call, and proves the inert VBA-only marker produces no search result. The candidate artifact also binds every public release asset, the release notes, runtime manifest, selected CI run, candidate run, and outer handoff checksums.

## Data-only publisher

Publication downloads the exact candidate artifact by numeric artifact ID and GitHub-reported digest. It rejects unexpected, nested, duplicate, linked, special, missing, or altered files; revalidates the release tag; creates a draft prerelease; uploads only the allowlisted candidate assets; downloads every uploaded asset; and compares exact byte lengths and SHA-256 identities before making the release public.

The publisher performs no checkout, Node/npm setup, Rust/Cargo setup, build, package generation, or execution of tag or artifact code under its write permission.

## Acceptance boundary

This release hardens release correctness and distribution provenance. Passing CI, the narrow real-Obsidian WebDriver scenario, publication, and public availability do not constitute owner field, performance, ranking, daily-drive, or final distribution acceptance. Beta.16 does not amend `CONTRACT.md`.

## Install

Install or update through BRAT using repository `cybersader/kwiry`, or download `kwiry-search.zip` from this release. The archive contains `main.js`, `manifest.json`, `styles.css`, GPL-3.0 licence text, and the complete third-party notice bundle.
