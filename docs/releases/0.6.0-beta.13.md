# kwiry-search 0.6.0-beta.13

This pre-release adds bounded Excel search to the no-daemon Obsidian profile and the
shared Rust core. It admits `.xlsx` and `.xlsm` without evaluating formulas, loading
external data, or opening macro payloads.

## One Obsidian index rebuild

The plugin cache schema moves from 10 to 11 and the Worker protocol from 11 to 12.
The first launch after updating therefore refuses the beta.12 cache and rebuilds the
active-vault index once. This is deliberate: Excel chunks carry a content-role field
and optional sheet/cell locator that older cache rows cannot represent honestly.

The native daemon's source-preparation schema does not move. Its per-format identity
model admits Excel without invalidating rows from Markdown, text, Base, Canvas, DOCX,
PDF, or Excalidraw. In the admission witness, all three pre-existing manifest rows
remained byte-identical and only the two new spreadsheet rows were added.

Rolling back to beta.12 is safe, but the plugin will rebuild its disposable cache in
that direction as well.

## Excel search

Excel is supported but **off by default**. Enable it under source-format settings when
you want `.xlsx` and `.xlsm` files indexed.

The extractor reads the stored OOXML SpreadsheetML package and indexes:

- visible cell text and stored cached formula values as primary content;
- formula text as searchable, unboosted latent content;
- hidden sheets, hidden rows, and hidden columns as searchable, unboosted content;
- classic cell comments as searchable, unboosted content;
- sheet names and defined names;
- shared strings, inline strings, booleans, errors, and stored numeric text without
  attempting to reproduce spreadsheet display formatting.

Formula results are exactly what the authoring application last stored in the file.
Kwiry never recalculates a workbook. A formula without a cached result contributes its
formula text only; no value is invented.

Results carry a stored-only sheet and A1 cell coordinate. Those coordinates do not
participate in ranking. Obsidian can identify the matching sheet/cell in the result,
but it cannot promise in-workbook cell navigation, so opening remains honest file-level
behavior.

## Macro and package boundary

An `.xlsm` file is searched through the same bounded ZIP/XML path as `.xlsx`, with a
strict macro boundary:

- `vbaProject.bin` and every canonical VBA part are never opened, decompressed, parsed,
  executed, or indexed;
- relabeling a VBA payload as workbook or worksheet XML quarantines the source before
  that entry is opened;
- external relationships, calculation chains, drawings, threaded comments, and other
  non-authorized parts are not dereferenced;
- DTDs and entity expansion are rejected;
- ZIP, XML, sheet, shared-string, comment, section, heading, and output-byte budgets are
  enforced before data is retained;
- one hostile spreadsheet is quarantined without stopping healthy sources in the same
  batch.

A test `.xlsm` containing a unique marker only inside its dummy VBA payload produced
zero search results for that marker.

## Ranking behavior

All formats continue to use the same text-evidence rules. Excel content classes do not
place scores into format-specific bands and cannot promote a weak cell above stronger
Markdown, DOCX, PDF, or other text evidence.

Latent Excel content remains searchable but receives no heading or technical-identifier
boost. At exactly equal scores, deterministic chunk identity orders primary before
supporting before latent content. Native Tantivy and in-plugin FTS5 carry the same rule.

## Formats

Enabled by default: Markdown, plain text, Base, Canvas, DOCX, Excalidraw.

Supported but off by default:

- **PDF** — pages are parsed and laid out rather than simply read.
- **Excel** — workbooks can contribute many cell records and should be enabled
  intentionally.

## Install

Install or update through BRAT using repository `cybersader/kwiry`, or download
`kwiry-search.zip` from this release. The archive contains `main.js`, `manifest.json`,
`styles.css`, GPL-3.0 licence text, and the complete third-party notice bundle.
